# 在线白板工具

一个简单易用的在线白板应用，支持基本的绘图功能。

## 功能特性

- **画笔工具**：自由绘制线条，可调整颜色和粗细
- **橡皮擦工具**：擦除不需要的内容
- **文本工具**：在画布上添加文本
- **形状工具**：绘制矩形、圆形和直线
- **画布操作**：支持清除画布和导出为PNG图片
- **响应式设计**：适配不同屏幕尺寸

## 使用方法

1. 从顶部工具栏选择要使用的工具
2. 调整颜色和线条粗细
3. 在画布上进行绘制操作
4. 使用清除按钮清空画布或导出按钮保存作品

## 技术实现

- 使用HTML5 Canvas API进行绘制
- 支持无限大画布（通过滚动实现）
- 响应式设计，适配各种屏幕尺寸
