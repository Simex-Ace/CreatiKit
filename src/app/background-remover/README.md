# 背景移除工具

这是一个简单但功能强大的背景移除工具，可以帮助用户将图片中的纯色背景（如白色）转换为透明背景。

## 功能特点

- 支持上传各种格式的图片文件
- 通过颜色距离算法智能识别并移除背景色
- 可调整阈值参数以精确控制背景移除效果
- 支持自定义目标背景色（RGB值）
- 实时预览处理效果
- 导出处理后的透明背景PNG图片

## 技术原理

1. 使用Canvas API加载并绘制用户上传的图片
2. 获取图片的像素数据数组
3. 遍历每个像素，计算其与目标背景色的RGB距离
4. 如果距离小于设定阈值，则将该像素的Alpha通道设为0（透明）
5. 将处理后的像素数据重新绘制到Canvas上
6. 通过Canvas的toDataURL方法将处理结果转换为PNG格式的图片URL

## 使用说明

1. 点击上传按钮，选择需要处理的图片文件
2. 调整阈值参数（0-100），值越小越精确，值越大移除范围越广
3. 如需更改目标背景色，请调整RGB值
4. 点击「移除背景」按钮开始处理
5. 处理完成后，可点击「下载图片」保存透明背景的PNG图片

## 最佳实践

- 对于背景色非常均匀的图片效果最佳
- 对于复杂背景，可以尝试调整阈值以获得最佳效果
- 如果主体与背景颜色相近，建议多次微调阈值

## 注意事项

- 过大的图片可能需要较长处理时间
- PNG格式支持透明通道，处理后的图片默认保存为PNG格式
- 处理完成后建议检查边缘效果，适当调整参数以获得理想结果
