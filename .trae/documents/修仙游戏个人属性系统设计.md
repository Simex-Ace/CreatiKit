# 修仙游戏角色状态系统综合设计

## 设计思路
将个人属性系统与生命值/法力值显示系统结合，创建一个完整的角色状态管理体系，包括基础属性、衍生属性、状态显示和影响机制，与现有游戏系统深度整合。

## 核心设计

### 1. 个人属性系统

#### 基础属性
- **体质**：影响生命值、修炼速度、防御力
- **根骨**：影响灵气容量、突破成功率、资源采集效率
- **悟性**：影响经验获得、技能学习速度、炼丹成功率
- **灵性**：影响灵气采集速度、符箓制作成功率、探险成功率
- **魅力**：影响宗门贡献、宠物捕捉成功率、交易价格

#### 属性影响机制
| 属性 | 影响效果 |
|------|----------|
| 体质 | 每点+5生命值，+1%修炼速度，+2防御力 |
| 根骨 | 每点+10灵气容量，+0.5%突破成功率，+1%资源采集效率 |
| 悟性 | 每点+1%经验获得，+1%技能学习速度，+0.5%炼丹成功率 |
| 灵性 | 每点+1%灵气采集速度，+0.5%符箓制作成功率，+0.5%探险成功率 |
| 魅力 | 每点+1%宗门贡献，+0.5%宠物捕捉成功率，±0.5%交易价格 |

### 2. 生命值与法力值系统

#### 核心状态
- **生命值（Health）**：角色生存能力，0时死亡或失去战斗能力
- **最大生命值（Max Health）**：由体质和境界决定
- **法力值（Qi）**：角色灵气储备，用于修炼、技能和符箓
- **最大法力值（Max Qi）**：由根骨和境界决定

#### 状态变化
- **生命值**：战斗伤害减少，休息/丹药恢复，突破提升上限
- **法力值**：修炼/技能消耗，采集/丹药恢复，突破提升上限

### 3. UI展示设计

#### 主界面状态栏
- 位置：屏幕顶部
- 内容：
  - 生命值条（红色）：显示当前/最大生命值
  - 法力值条（蓝色）：显示当前/最大灵气
  - 属性面板入口：点击展开详细属性
  - 状态图标：显示当前buff/debuff

#### 属性详情面板
- 显示所有基础属性值
- 显示属性对衍生属性的影响
- 显示装备和丹药的加成
- 显示属性提升的历史记录

#### 战斗界面
- 放大显示生命值和法力值
- 实时更新数值变化
- 伤害/恢复的浮动文字
- 低生命值警告效果

## 实现步骤

### 1. 类型定义扩展（types.ts）
- 扩展 `CultivationInfo` 接口，添加：
  - `attributes` 对象（包含5种基础属性）
  - `health` 和 `maxHealth` 字段
- 确保 `Resources` 接口中的 `qi` 字段与法力值对应

### 2. 初始化与计算（game-core.ts）
- 在 `createNewGame` 函数中初始化属性和生命值
- 添加属性计算函数：
  - `calculateMaxHealth`：基于体质和境界
  - `calculateAttributeGrowth`：修炼时的属性提升
  - `applyAttributeEffects`：属性对各系统的影响
- 更新现有计算函数，纳入属性影响

### 3. 辅助函数更新（utils.ts）
- 添加 `calculateAttributeBonus`：计算属性对特定系统的加成
- 更新 `getCultivationLevelInfo`：返回属性成长值
- 添加 `formatAttributeValue`：格式化属性显示

### 4. UI组件实现
- 创建 `StatusBar` 组件：显示生命值、法力值和状态图标
- 创建 `AttributePanel` 组件：显示详细属性信息
- 集成到主界面 `page.tsx`
- 添加动画效果和交互反馈

### 5. 与现有系统整合
- **修炼系统**：属性影响修炼速度和突破成功率
- **技能系统**：属性影响技能学习和效果
- **资源系统**：属性影响采集效率和制作成功率
- **探险系统**：属性影响探险成功率和奖励
- **战斗系统**：生命值和属性影响战斗结果
- **丹药系统**：添加属性提升类丹药
